---
title: FingerprintData
description: Data object with all fingerprint getters
---

This class holds all fingerprint data. It implements `JsonSerializable` for direct use with `json_encode()`.

## Core Getters

| Method | Returns | Description |
|--------|---------|-------------|
| `getVisitorId()` | `?string` | Unique fingerprint hash |
| `getRequestId()` | `?string` | Request identifier |
| `getConfidence()` | `?float` | Confidence score from 0 to 1 |
| `getCreatedAt()` | `?int` | Unix timestamp |

## Utility Methods

### toArray

Returns all data as an associative array:

```php
$array = $fingerprint->toArray();
```

### jsonSerialize

Same as `toArray()`. Makes the object work with `json_encode()`:

```php
echo json_encode($fingerprint, JSON_PRETTY_PRINT);
```
