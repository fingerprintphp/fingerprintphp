## Introduction

This package provides a PHP wrapper for browser fingerprinting. It generates a unique visitor identifier that persists across sessions, incognito mode, and cookie purges. You get a JavaScript snippet for your frontend and a storage layer for your backend.

## Quick Example

Here's how you can use it:

```php
use Fingerprintphp\FingerprintClient;

$client = new FingerprintClient();

// Output the JavaScript snippet in your HTML
echo $client->getJavaScript(['endpoint' => '/fingerprint.php']);

// Handle the incoming fingerprint in your endpoint
$fingerprint = $client->handleRequest();
echo $fingerprint->getVisitorId();
```

The JavaScript collects browser attributes and POSTs them to your endpoint. The PHP handler stores the fingerprint and returns it for later lookup.
